## Features

### KillAura

Configurable combat module with settings for range, targets, rotations and attack delay.

### Fly

Movement module with different flight settings and adjustable speed.

### Xray

Makes selected blocks easier to find by hiding or filtering other blocks.

### ESP

Shows entities through walls and displays useful information such as names and distance.

## ClickGUI

All modules can be managed through the ClickGUI.

You can enable or disable modules, change their settings, assign keybinds and save your configuration.

The interface is kept fairly simple so you don't have to dig through multiple menus just to change one setting.

## Configuration

Client settings can be saved into profiles.

For example, you can keep separate configurations for PvP, testing or general gameplay and switch between them when needed.
